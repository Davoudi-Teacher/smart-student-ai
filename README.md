# Smart Student AI
## سامانه هوشمند شناسایی و تحلیل عملکرد تحصیلی دانش‌آموزان

### معرفی پروژه
این پروژه یک سامانه آموزشی مبتنی بر هوش مصنوعی است که با هدف مدیریت، نمایش و تحلیل عملکرد تحصیلی دانش‌آموزان طراحی شده است.

### امکانات اصلی
- داشبورد مدیریتی و گزارش‌های آماری
- مدیریت پرونده دانش‌آموزان
- ذخیره اطلاعات با پایگاه داده SQLite
- تشخیص چهره با OpenCV و Haar Cascade
- تولید و خواندن QR Code
- تحلیل نمرات و حضور و غیاب
- پیش‌بینی وضعیت تحصیلی با الگوریتم Random Forest
- نمایش نمودارهای تحلیلی

### فناوری‌های استفاده‌شده
Python، Streamlit، Pandas، NumPy، Scikit-learn، OpenCV، Plotly، SQLite

### ساختار پروژه
- `app.py`: برنامه اصلی
- `data/`: داده‌ها و ابزارهای تولید داده
- `database/`: پایگاه داده
- `models/`: مدل یادگیری ماشین و نمودارهای ارزیابی
- `modules/`: ماژول‌های پردازش تصویر، QR و تحلیل تحصیلی
- `train_ml_model.py`: آموزش مدل
- `requirements.txt`: کتابخانه‌های موردنیاز

### نصب و اجرا
```bash
git clone https://github.com/Davoudi-Teacher/smart-student-ai.git
cd smart-student-ai
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

### مدل یادگیری ماشین
در این پروژه از الگوریتم Random Forest برای پیش‌بینی وضعیت تحصیلی استفاده شده است. مدل با داده‌های مصنوعی آموزش دیده و دقت آزمایشی آن حدود ۵۲ درصد بوده است.

### محدودیت‌ها
- تشخیص چهره فعلی فقط برای شناسایی وجود چهره است و قابلیت تشخیص هویت افراد را ندارد.
- داده‌های آموزشی مصنوعی هستند.
- مدل فعلی نمونه‌ای آموزشی است و برای تصمیم‌گیری واقعی درباره دانش‌آموزان اعتبارسنجی نشده است.
- توکن‌های QR برای نمایش آزمایشی طراحی شده‌اند و برای استفاده واقعی به امنیت بیشتری نیاز دارند.

### حریم خصوصی
این پروژه برای اهداف آموزشی طراحی شده است. از انتشار اطلاعات واقعی، تصاویر و مشخصات خصوصی دانش‌آموزان خودداری کنید.
