# سامانه هوشمند مدیریت و تحلیل اطلاعات دانش‌آموزان

**مخزن:** https://github.com/Davoudi-Teacher/smart-student-ai

## معرفی
این پروژه یک سامانه تحت وب آموزشی مبتنی بر Python و Streamlit است که برای یکپارچه‌سازی پرونده دانش‌آموز، مدیریت نمرات، حضور و غیاب، تحلیل آموزشی، گزارش‌گیری و مدیریت کاربران توسعه داده شده است.

## قابلیت‌ها
- ثبت و مشاهده پرونده دانش‌آموزان
- ثبت چند تصویر نمونه و ذخیره الگوهای ویژگی چهره
- پردازش تصویر و مسیر آزمایشی تشخیص چهره با OpenCV، YuNet و SFace
- تولید و خواندن QR Code برای بازیابی پرونده
- مدیریت نمرات: ثبت، مشاهده، ویرایش و حذف
- تحلیل میانگین درس‌ها و روند دوره‌ای
- ثبت و مدیریت حضور و غیاب
- داشبورد تحلیل کلاس و مدرسه با نمودارها و فیلترها
- تولید گزارش PDF با پشتیبانی از متن فارسی
- احراز هویت کاربران، هش رمز عبور، رمز موقت و تغییر اجباری رمز
- نقش‌های مدیر، معاون آموزشی و هنرآموز و تخصیص کلاس/درس

## فناوری‌ها
Python، Streamlit، SQLite، Pandas، Plotly، OpenCV، YuNet، SFace، QR Code و ابزارهای تولید PDF.

## اجرای پروژه
> دستورها باید با ساختار واقعی پوشه و نسخه نهایی requirements.txt تطبیق داده شوند.

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m streamlit run app.py
```

## نکات امنیت و حریم خصوصی
- از داده ساختگی برای نمایش و آزمون استفاده کنید.
- پایگاه داده واقعی، تصاویر دانش‌آموزان، رمزها و اطلاعات شخصی را در مخزن عمومی قرار ندهید.
- پوشه محیط مجازی و فایل‌های محلی را در `.gitignore` قرار دهید.
- تشخیص چهره در این پروژه یک قابلیت کمکی و نیازمند ارزیابی است؛ خروجی آن نباید به‌تنهایی مبنای تصمیم آموزشی یا انضباطی باشد.
- پیش از استفاده عملی، مجوزها و رضایت‌های لازم، کنترل دسترسی، امنیت سرور و سیاست نگهداری داده را بررسی کنید.

## وضعیت آزمون
برخی جریان‌های اصلی در محیط توسعه به‌صورت دستی آزمایش شده‌اند؛ از جمله ورود مدیر، تولید رمز موقت و تغییر اجباری رمز، مدیریت نمرات، ثبت حضور و غیاب و تخصیص سطح دسترسی. بررسی نحوی کد به‌تنهایی تضمین‌کننده عملکرد کامل نیست؛ اجرای نصب تمیز و آزمون یکپارچه پیش از انتشار توصیه می‌شود.
